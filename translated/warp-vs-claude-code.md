# Warp 与 Oz 入门 | Warp

介绍 Oz：面向云智能体的编排平台。了解更多。

Warp 是一个智能体化开发环境，它将现代化终端与强大的智能体相结合，帮助你构建、测试、部署和调试代码。Warp 的 AI 由 Oz 驱动——Oz 是面向云智能体的编排平台。

Warp 将现代化终端与 Oz（面向云智能体的编排平台）融为一体

## Warp

Warp 是你工作的地方——一个为配合智能体编程而打造的快速、现代化终端。

核心能力：

- **智能体模式**：在用于执行命令的清爽终端与用于多轮智能体工作流的专属对话视图之间自由切换。
- **现代化终端体验**：光标移动、基于块的导航、多行编辑、语法高亮和丰富的补全。使用 Rust 构建，性能出色。
- **代码编辑器**：文件树、支持 LSP 的代码编辑器，以及交互式代码评审体验。
- **编码智能体集成**：语音输入、使用 @ 选择来操作基于终端的图像等功能。兼容 Oz，也兼容 Claude Code 和 Codex 等智能体。

## Oz：面向云智能体的编排平台

Oz 是面向云智能体的编排平台，为 Warp 的所有智能特性提供动力。Oz 旨在大规模协调智能体——理解你的代码库、自主执行任务并适配你的工作流。Oz 天生支持多模型，让你可以灵活地为每项任务选择最合适的大语言模型。

Oz 以两种模式运行：

### 本地智能体

直接在 Warp 应用中运行，提供实时、交互式的编程辅助。

- 在整个代码库中编写和重构代码
- 调试问题并修复错误
- 运行命令并解读结果
- 规划并执行多步骤任务

本地智能体让你始终掌控局面。你可以审查变更、在任务中途引导智能体，并在动作执行前进行批准。

→ 开始使用本地智能体

### 云智能体

Oz 云智能体在 Warp 的基础设施（或你自己的基础设施）上后台运行，用于大规模自动化。

- **触发器**：响应来自 Slack、Linear、GitHub 或自定义 Webhook 的事件
- **定时任务**：运行依赖更新、死代码清理等周期性任务
- **并行性**：跨仓库或任务并发运行多个智能体
- **可观测性**：每一次运行都可被跟踪、审计，并与团队共享

云智能体非常适合不需要你立即关注的工作，例如拉取请求评审、工单分流、日常维护，以及集成驱动的工作流。

## 它们如何协同工作

Warp 与 Oz 在本地和云开发之间提供统一体验：

- **同一个智能体，随处可用**：无论你是在 Warp 中交互式地工作，还是在云端运行智能体，使用的都是同一套底层智能体能力。
- **无缝交接**：在云端启动任务，当你想亲自掌控时，可在本地 Warp 中接手，且不丢失进度或上下文。
- **共享上下文**：Warp Drive、规则和 MCP 服务器在本地与云智能体之间通用，因此团队的知识和工具始终可用。
- **团队协作**：共享智能体会话、审查智能体的动作、引导正在运行的任务，无论任务最初由谁发起。

## 多模型支持

Oz 天生支持多模型。你可以从一组精选的顶级模型中，选择你偏好的大语言模型。

## 隐私与安全

Warp 符合 SOC 2 标准，并与所有签约的大语言模型提供商签订零数据留存政策。任何客户 AI 数据都不会被留存、存储或用于训练。

Warp 的 AI 功能可在「设置 > AI」中全局关闭。
