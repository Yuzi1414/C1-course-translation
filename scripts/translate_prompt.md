# C1 翻译管线 · 第 2 步：翻译指令模板

> 这是每次翻译一篇文章时，发给 AI 的**固定指令模板**。逐篇复用，保证风格、术语、格式统一，做到"换一门课也能复跑"。

## 固定翻译指令（Prompt 模板）

```
你是专业科技翻译。请把下面这篇英文技术文章翻译成简体中文，要求：

1. 术语强制一致：必须使用「术语表」里的译法，不得另起译名。
   - 术语首次出现写为「中文（English，缩写）」，之后只用中文。
   - 专有名词（GitHub、Kubernetes、Claude、Codex、Copilot、Devin、Warp、Semgrep、Anthropic、OpenAI、Slack、Linear、Rust 等）保留英文。
2. 忠实原文：不增删信息、不改写观点、不夹带解释，逐句翻译。
3. 技术语气：客观、专业，不用口语化网络用语。
4. 保留结构：标题层级（# / ## / ###）、列表、段落、链接锚点文字全部保留原层级与顺序。
5. 代码、命令、变量名、文件路径：一律不翻译，保持原样。
6. 输出格式：只输出译文，不要任何开头/结尾的说明或"以下是翻译"之类的套话。

【术语表】
<粘贴 glossary.md 全文>

【待翻译原文】
<粘贴该篇 source/*.md 的正文>
```

## 使用方式（每篇重复这 4 步）

1. 打开 `source/<文章名>.md`，复制正文。
2. 把正文粘贴到上面模板的「待翻译原文」处。
3. 发送给 AI（我）。
4. 把 AI 返回的译文保存为 `translated/<文章名>.md`。

## 可复跑性说明

- 同一篇 + 同一模板 + 同一术语表 → 输出稳定一致。
- 换一门课：只需替换「术语表」和「source/ 目录」，模板本身不动。
